# MiSans

本应用使用 MiSans 字体。

- 文件：`MiSans-Regular.ttf`，用户提供的原始字体，未进行裁剪、转换或修改。
- 字体信息：MiSans Regular，Version 4.009。
- 字体内版权声明：Copyright © 2020-2025 Beijing Xiaomi Mobile Software Co.,Ltd. All Rights Reserved.
- 官方网站：https://hyperos.mi.com/font/zh/
- 官方使用说明：https://hyperos.mi.com/font/zh/faq/
- 官方许可原文：同目录 `MiSans-License.pdf`。
- 许可文件来源：https://hyperos.mi.com/font-download/MiSans%E5%AD%97%E4%BD%93%E7%9F%A5%E8%AF%86%E4%BA%A7%E6%9D%83%E8%AE%B8%E5%8F%AF%E5%8D%8F%E8%AE%AE.pdf

发布应用时应将字体、此说明及许可文件一同打包，并保留工具页的字体声明。
字体许可独立于应用代码许可。具体使用条件以官方许可原文为准。

目前仅包含 Regular 字重。标题和课程名沿用界面的强调样式，并未添加独立的 Medium 或 Semibold 字体文件。
`SIMHEI.TTF` 为原有项目文件，当前应用不再引用它。
